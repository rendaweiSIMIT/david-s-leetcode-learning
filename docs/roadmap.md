# 算法面试学习路线

路线按能力依赖排列，不按 LeetCode 题号排列。长期稳健版本通常需要 16–24 周；本项目根据 2026-09-20 启动求职的计划执行压缩版，具体课表见 [curriculum.md](curriculum.md)，日历见 [sprint_plan.md](sprint_plan.md)。压缩训练先在一个月内建立完整基础地图，再用 15 天重复与模拟提高稳定性；最后一周与求职投递并行。

## Phase 0：基线与 Python 手写恢复（1 周）

- Python 常用容器、切片、推导式、排序、函数与类型标注
- `list`、`dict`、`set`、`deque`、`heapq` 的复杂度与适用场景
- 渐进复杂度、摊还分析、递归调用栈
- 手写输入解析、断言测试、常见边界
- 完成一次不依赖 AI 的基线诊断

通过标准：能脱离补全工具写出常用操作，并准确说明复杂度。

## Phase 1：数组、字符串与哈希（2–3 周）

- 遍历与原地修改
- 双指针、快慢指针、滑动窗口
- 前缀和、差分
- 计数、分组、去重与哈希映射
- 区间与矩阵基础

通过标准：对常见 O(n²) 方案，能主动寻找单调性、重复计算或查找瓶颈并优化。

## Phase 2：链表、栈与队列（2 周）

- 单/双链表操作，虚拟头结点
- 反转、合并、环、相交
- 栈、队列、单调栈、单调队列
- 表达式与括号类问题

通过标准：能画清指针变化，避免断链，并独立处理空节点与首尾边界。

## Phase 3：二分与排序（2 周）

- 常见排序算法及稳定性
- 二分查找的统一边界模型
- 答案二分
- 分治与归并思想

通过标准：能根据区间不变量写出无死循环、无越界的二分代码。

## Phase 4：树、BST、堆与 Trie（3 周）

- DFS/BFS，递归与迭代遍历
- 高度、直径、路径、最近公共祖先
- BST 性质与操作
- 优先队列、Top-K、数据流
- Trie 与字符串索引

通过标准：能区分“从子树收集信息”和“沿路径维护状态”两类递归。

## Phase 5：回溯与搜索（2 周）

- 子集、排列、组合
- 剪枝、去重、状态恢复
- 网格搜索

通过标准：能明确选择列表、路径状态、终止条件，并估算搜索空间。

## Phase 6：图与并查集（3 周）

- 图的表示、DFS/BFS
- 拓扑排序
- 并查集
- 最短路与最小生成树基础

通过标准：能从依赖、连通、传播或路径语义识别对应模型。

## Phase 7：动态规划与贪心（3–4 周）

- 状态、选择、转移、初值与遍历顺序
- 线性、网格、背包、子序列、区间 DP
- 贪心选择与正确性论证

通过标准：能从暴力递归推导记忆化和递推，而不是背转移方程。

## Phase 8：综合冲刺（持续进行）

- 每周限时机试
- 45 分钟手撕模拟：澄清、方案、编码、测试、追问
- 高频题间隔复习
- 针对目标公司补充题型，而非泄露题或背原题

通过标准：在陌生中等题上稳定完成沟通、正确实现和复杂度分析。

## 每周建议节奏

- 2 次概念与基础实现（每次 60–90 分钟）
- 2 次模式题训练（每次 60–90 分钟）
- 1 次限时混合训练（60–120 分钟）
- 1 次错题复习（30–60 分钟）
- 每天可额外安排 15 分钟无提示复写

正确率和复现能力优先于题量。初期建议每周 8–12 题，稳定后再增加。
