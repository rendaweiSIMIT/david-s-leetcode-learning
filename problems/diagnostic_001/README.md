# Diagnostic 001

本目录用于首次基线诊断。请先阅读 `sessions/001_2026-08-13_baseline_diagnostic.md`。

## 1. Two Sum Indices

给定整数列表 `nums` 和整数 `target`，返回两个不同下标 `[i, j]`，使 `nums[i] + nums[j] == target`。假设恰好有一组答案，不允许重复使用同一元素。下标顺序不限。

## 2. Valid Brackets

字符串只包含 `()[]{}`。判断所有括号是否类型匹配且闭合顺序正确。空字符串视为有效。

## 3. Lower Bound

给定非递减整数列表 `nums` 和整数 `target`，返回第一个大于或等于 `target` 的元素下标；若不存在，返回 `len(nums)`。

不要在 README 中写答案。思路、不变量与复杂度请写在 `solution.py` 对应位置，以便后续复盘。
